# Editorial photography

`public/editorial/` holds room and material photography used to give the site a sense of place.
It is **not** the project archive. Real, owner-supplied project photographs live in
`public/portfolio/` and are the only images presented as completed work.

Every image below is served through `next/image`, so keep sources at least twice the size of the
largest slot they appear in. All current files are WebP.

## How these images may be described

- Category and contact imagery is **inspiration / atmosphere**, not a record of work by Desired
  Homes Interiors. Captions say so where the distinction could be misread.
- The hero is an editorial room photograph. It must not be labelled as a completed project.
- The five images in `public/portfolio/` are the supplied project photographs. Only those may be
  captioned as project work.

## Adding or replacing an image

1. Add the file here with a descriptive, lower-case name.
2. Record its source, author, licence and dimensions in the table above.
3. Use a 4:5 portrait crop for category tiles and the material study; the hero is landscape.
4. Write specific `alt` text describing the room or material, not the marketing intent.
5. Keep the caption honest: say “editorial image” when it is not a completed project.
